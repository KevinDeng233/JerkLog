# JerkLog

Habits · Training · Nutrition。面向成年用户的本地优先记录工具。

**当前为 Phase 1A：Habits 完整记录功能。Training 与 Nutrition 保持 Phase 0 占位。**

## 启动与检查

需要 Node.js >=22.18 与 npm；CI 使用 Node 22.18.0。

```sh
npm ci
npm run dev
npm run lint
npm run typecheck
npm run test
npm run build
npm run preview
```

浏览器测试：构建后运行 `npm run test:e2e`。需要已安装 Google Chrome；脚本自动管理本机 4173 端口的生产预览，覆盖桌面与移动视口。固定使用同一浏览器、协议、主机和端口访问自己的本地数据。

## 本轮功能

- 一键记录当前时间；1.5 秒重复点击保护在界面与数据库事务两层执行，覆盖刷新及不同标签页。同一时间的补录在 1.5 秒内也会阻止重复提交，明确不同的事件时间不受此限制。
- 手动补录、编辑发生时间、确认删除；所有写入都有失败提示。
- 撤销最近一次新增、编辑或删除，刷新后仍有效。只保留一次撤销，不支持重做；跨标签页发生冲突时拒绝覆盖其他修改。
- Dashboard 与 Habits 实时计算今日、本周、近 7/30 天次数、最近一次时间；近 30 天趋势附每日数据表；历史按每页 20 条浏览，不使用演示数据。
- 月历按周一排版，可逐月切换、点击日期查看记录。每格显示次数，颜色不代表健康评分。
- 默认深色、亮色与系统主题；整活/专业文案切换不影响原始记录或统计。操作反馈使用可关闭 Toast；成功提示 6 秒后消失，错误提示保留至关闭或下一操作。
- 加载状态与读取失败提示独立呈现，不把读取失败当作零记录。

## 日期规则

时间以 ISO UTC 存储，界面按浏览器当前时区分组。本周从周一当地零点开始；最近 7/30 天分别含今天与之前 6/29 个当地自然日，截止当前时间。夏令时采用自然日边界，不用固定 24 小时推算天数。计时器与回到窗口会更新跨午夜/月统计。

输入不存在的本地时间（例如夏令时跳过的时刻）会被拒绝。夏令时回拨的重复时间可选择较早或较晚一次；未修改发生时间的编辑保留原时间精度。更换时区会改变按日归属，原始时间不变。

## 数据与隐私

Dexie schema v2 保留 v1 表结构与现有记录，增加 createdAt 索引及仅本地的 habitState 控制表，用于重复点击保护和最近操作撤销。迁移测试使用真正的 v1 数据库验证记录与设置保留。不通过删库解决错误。

记录和偏好只存于当前浏览器 IndexedDB，无账号、云端同步、遥测、广告、第三方统计或错误上报 SDK。不向控制台输出记录或原始数据库错误，不把记录放进 URL 或网络请求。本地存储不等于加密；清除浏览器数据可能丢失全部记录。备份与离线应用缓存尚未实现。

仅供成年用户自我管理，不替代医疗建议；不依据习惯推断健康、营养流失、热量消耗或训练能力。没有羞辱评分、连续打卡惩罚或强制戒断。

## 测试与环境边界

Vitest 覆盖 CRUD、持久化、撤销与并发冲突、重复点击、错误回滚、schema 迁移、日期统计与夏令时。保留并更新 Phase 0 回归测试，没有删除或跳过失败测试。基础 CI 执行 lint/typecheck/test/build；Chrome 流程另行本地执行。

本机 Kaspersky 会注入 HTTP 脚本；浏览器测试只在隔离上下文中阻断该明确识别的注入地址后检查应用请求，不修改安全软件设置。Windows 沙箱下开发依赖预打包可能仍需额外目录读取权限；脚本采用 Node 原生配置加载。未验证手机真机、Safari、离线冷启动或大规模记录性能。
