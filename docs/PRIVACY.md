# 隐私说明 · Phase 1C

习惯、训练计划/动作/组/活动时间段、历史快照、撤销状态、饮食食品/记录/目标/忌口及偏好只保存在当前浏览器 IndexedDB。公共动作和食品目录为打包的离线静态文本，无远程图片、运行时食品/健身 API、账号或后台同步。

应用不将个人记录放进网络请求、URL 或控制台，不接入广告、遥测、第三方统计或错误上报 SDK。未知存储异常使用固定消息呈现，不展示敏感数据库内容。静态资源与本机开发热更新不携带记录；系统安全软件和浏览器扩展联网不由应用控制。公开 USDA 来源链接仅在用户主动打开时访问，并设置 no-referrer，不携带饮食数据。

Nutrition 与 Training 不根据 Habits 判断健康、恢复、营养、热量或训练表现；Nutrition 推荐/计算不读取 Habits 或 Training。营养目标完全自选；推荐可关闭，不能从未记录饮食诊断缺乏。成人估算器的年龄、身高、体重、公式系数及适用性选择仅暂存在组件内存，不保存为个人档案；主动保存的目标与饮食偏好才会持久化。

删除食品不会删除日记中的营养/来源快照；删除计划/动作不会删除训练快照。放弃未完成训练会在确认后删除该次训练及其组。Habits 最近一次删除的快照可为撤销暂存，下一次习惯操作会替换它。Nutrition 操作控制会暂存最近提交签名以防重复，仍只在本机。

v4 迁移只补充 Nutrition 字段并增加 Nutrition 控制/偏好表，不重置数据库、不写入 Habits/Training/Settings。旧 Nutrition 原字段及可用历史事实保留；不从现有食品猜测旧摄入营养。

本地存储不是加密，清除站点数据或浏览器回收空间可能使记录丢失。备份/导入、Service Worker 和离线冷启动尚未实现；已加载页面离线读取经过测试。不宣称本地数据是加密保险库。仅供自主记录，不构成医疗建议。
