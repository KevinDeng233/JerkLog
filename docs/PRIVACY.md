# 隐私说明 · Phase 1B

习惯、训练计划、动作、组、训练时间段、历史名称快照、撤销状态及偏好只保存在当前浏览器 IndexedDB。动作目录为离线静态文本，无远程图片、第三方食品/健身 API、账号或后台同步。

应用不将记录放进网络请求、URL 或控制台，不接入广告、遥测、第三方统计或错误上报 SDK。未知存储异常使用固定消息呈现。加载静态资源和本机开发热更新连接不携带记录；系统安全软件及浏览器扩展的联网行为不由应用控制。

Training 不根据 Habits 判断健康、恢复、营养、热量或训练表现。容量、次数、强度与计时仅供自主回顾，不构成医疗建议或统一训练处方。

删除计划/自定义动作不会删除历史快照；历史中保留记录时的名称与背景。放弃未完成训练会在确认后删除该次训练及其组。本地存储不是加密；清除站点数据或浏览器回收空间可能使记录丢失，备份与离线冷启动尚未实现。

Habits 最近一次删除的快照可为撤销而在本机暂存，下一次习惯操作会替换它；本次训练迁移不写入这些表。
