# 隐私说明 · Phase 1A

习惯发生时间、创建/更新时间、最近一次撤销快照及设置仅存在当前浏览器 IndexedDB。删除的最近记录在撤销状态中暂留副本；下一次记录操作替换撤销快照，或撤销时消耗该状态。没有后台同步、账号、遥测、广告、第三方统计或错误上报 SDK。

应用不把记录放进网络请求、URL 或控制台日志；未知数据库错误显示固定提示，不暴露原始异常文本。加载静态资源与开发热更新需要同源连接，均不携带记录。系统软件或浏览器扩展的联网行为不由应用控制。

本地存储不是加密。具有当前浏览器配置文件访问权限的人可能读取数据。清除站点数据、关闭隐私窗口或浏览器回收空间可能丢失记录；备份与离线冷启动尚待后续阶段。请固定使用同一浏览器与来源访问记录。

仅供成年用户自我管理，不替代医疗建议。不根据习惯次数推断身体健康、热量消耗、营养流失或训练能力；无羞辱评分或强制戒断机制。
