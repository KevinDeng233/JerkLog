# 隐私说明（Phase 1 草稿）

JerkLog 的私人记录与设置仅存于当前浏览器 IndexedDB，不登录、不上传、不接入广告、分析或错误上报 SDK。不将习惯记录用于健康、营养、热量或训练推断。

浏览器本地存储不是加密。具有该浏览器配置文件访问权限的人可能读取数据；清空站点数据、隐私窗口关闭或浏览器空间回收可能导致丢失。Phase 1 尚无导出备份；建议仅进行功能验收。

浏览器加载应用时会请求静态资源；开发环境还使用本机 Vite 热更新连接。这些请求不携带用户记录。测试只使用合成数据，浏览器测试产物被 Git 忽略。Phase 3 才加入离线资源缓存与明文 JSON 备份风险提示。
